## ⭐ Featured Projects

### 🤖 [AI Documents Chatbot](https://github.com/ENGABHAY/Ai-Documents-Chatbot-Langchain)
Upload a document and ask questions answered **only from that document**.
**LangChain · ChromaDB · all-MiniLM-L6-v2 · Groq · Streamlit** — supports PDF, TXT, DOCX, CSV, XLSX, PPTX and HTML, with MMR retrieval.

### 🎥 [AI Smart Exam Proctoring System](https://github.com/ENGABHAY/AI-Smart-Proctoring-System)
Real-time suspicious-activity detection from webcam or video, with saved evidence frames and a CSV log.
**YOLOv8n · OpenCV · Python** — custom-trained on 4 classes (book, phone, headphone, person):
**Precision 0.890 · Recall 0.932 · mAP50 0.931**

### 📰 [AI News Event Clustering & Timeline Builder](https://github.com/ENGABHAY/AI-News-Event-Clustering-Timeline-Builder)
Groups news articles into real-world events and builds timelines.
**SBERT · UMAP · HDBSCAN · BART/Gemini summaries · Streamlit** — **209,508 articles → 4,820 events.**
